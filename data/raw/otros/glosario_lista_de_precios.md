# Glosario de la lista de productos

Las descripciones de la lista usan abreviaturas. Este glosario sirve para interpretarlas cuando un cliente pregunta qué significa algo de una descripción.

## Prefijos de categoría

| Abreviatura | Significado |
|---|---|
| NB | Notebook |
| MB | Motherboard (placa madre) |
| VGA | Placa de video |
| CPU | Procesador |
| MEM | Memoria RAM (MEM NB = memoria para notebook, formato SO-DIMM) |
| HD INT. / HD EXT. | Disco rígido interno / externo |
| SSD | Disco de estado sólido |
| FUENTE | Fuente de alimentación de PC |
| AUR | Auriculares |
| PAR | Parlante |
| CEL | Celular |
| RELOJ | Reloj inteligente (smartwatch) |
| APPLE AC | Accesorio Apple |
| COOLER P/CPU | Disipador para procesador |
| COOLER GAB / COOLER FAN | Ventilador para gabinete |
| COOLER LIQUID | Refrigeración líquida AIO (todo en uno) |

## Procesadores

| Abreviatura | Significado |
|---|---|
| S/COOLER | Sin cooler: hay que comprar un disipador aparte |
| C/COOLER | Con cooler de fábrica incluido |
| 19MB, 38MB, 96MB... | Memoria caché total (L2 + L3) |
| X3D | Ryzen con 3D V-Cache: mucha caché extra, ideal para juegos |
| G (ej. 8600G) | Ryzen con gráficos integrados potentes (APU) |
| F (ej. 7500F, 12400F) | Sin gráficos integrados: necesita placa de video |
| K / KF (Intel) | Multiplicador desbloqueado para overclock; KF además sin gráficos integrados |

## Motherboards

| Abreviatura | Significado |
|---|---|
| AM4, AM5, 1200, 1700, 1851 | Socket (1700 = LGA1700, etc.) |
| MATX / ATX / EATX / ITX | Formato de la placa: Micro-ATX, ATX, Extended ATX, Mini-ITX |
| 2M.2, 4XM.2 | Cantidad de slots M.2 para discos NVMe |
| D4 (ej. H610M-K D4) | Versión con memoria DDR4 |
| WIFI6E / WIFI7 | Estándar de Wi-Fi integrado |

## Placas de video

| Abreviatura | Significado |
|---|---|
| 12GB/GDDR7 | Cantidad y tipo de memoria de video |
| 2FAN / 3FAN | Cantidad de ventiladores |
| OC | Viene con overclock de fábrica (algo más de frecuencia) |
| SFF | Small Form Factor: cumple medidas para gabinetes compactos |
| ICE / WHITE / WHI | Versión de color blanco |
| BTF | Conectores de alimentación en la parte trasera; requiere motherboard compatible |

## Fuentes

| Abreviatura | Significado |
|---|---|
| 80 PLUS BRONZE / GOLD / PLATINUM | Certificación de eficiencia (de menor a mayor) |
| FULL MODULAR / SEMI MODULAR / NO MODULAR | Si los cables se pueden desconectar |
| REAL | Potencia real (en fuentes económicas, para diferenciar de la potencia pico) |
| SFX | Formato compacto para gabinetes chicos |

## Notebooks

Formato típico: `PROCESADOR FRECUENCIA/RAM/ALMACENAMIENTO/PANTALLA/.../SO/IDIOMA/COLOR`.

| Abreviatura | Significado |
|---|---|
| 16GBD5 | 16 GB de RAM DDR5 |
| 512SSD / 1TBSSD | Almacenamiento SSD |
| EMMC / UFS | Almacenamiento soldado más lento que un SSD (equipos de entrada) |
| W11 / W11PRO | Windows 11 Home / Pro |
| ING / ESP | Teclado en inglés / español |
| ULT 7 / ULTRA 7 | Intel Core Ultra 7 |
| AI 9 / IA R9 | AMD Ryzen AI 9 |

## Celulares y Apple

| Abreviatura | Significado |
|---|---|
| 256GB/8GB | Almacenamiento / RAM |
| DUAL | Dual SIM |
| ESIM | Funciona con SIM virtual |
| *ANATEL* | Homologado en Brasil |
| CPO | Reacondicionado certificado por el fabricante |
| LL/A, LA/A, BE/A, LE/A | Mercado de origen de un producto Apple (EE. UU., Latinoamérica, Brasil, Argentina) |
| (PLUG BR) / (PLUG ARG) | Tipo de enchufe del cargador incluido |
| 10C/10C | Núcleos de CPU / núcleos de GPU en chips Apple |

## Garantía

| Abreviatura | Significado |
|---|---|
| 1GTA, 2GTA, 3GTA | 1, 2 o 3 años de garantía del fabricante |
| .PY / .BR / BR-PY | Distribuidor que gestiona esa garantía (Paraguay / Brasil) |
| (GTA BRASIL) | Garantía gestionada por el distribuidor de Brasil |
| NUEVA S/CAJA / BULK | Producto nuevo sin caja comercial |
